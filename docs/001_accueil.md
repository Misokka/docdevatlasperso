## Bienvenue

DevAtlas est ma documentation de développement : concepts, exemples de code, architectures et bonnes pratiques que je veux retrouver facilement dans mes projets.

- Navigue par rubrique à gauche.
- Recherches globales avec **Cmd/Ctrl + K** : un mot comme `Auth::attempt`, `hasMany`, `LEFT JOIN`, `onMounted`, ou `Dockerfile` retrouve aussi le contenu des fiches.
- Les blocs de code se copient en un clic.

## Ce que ce site n'est pas

Ce n'est pas la documentation officielle des frameworks. Les exemples simplifient parfois le contexte et doivent être adaptés à la version et au projet. Des liens officiels sont indiqués dans les fiches importantes.
