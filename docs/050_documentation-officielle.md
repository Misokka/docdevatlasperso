## Utiliser une documentation personnelle

Une documentation personnelle sert d’**aide-mémoire** pour retrouver un concept ou une syntaxe exacte. Lorsqu’un comportement dépend d’une version, vérifie toujours la documentation officielle correspondante.

**N'expose jamais d’identifiants, de secrets ou de données client dans un dépôt public.**
